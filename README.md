**Sprited** is an open source sprite editor for Android.

# Features

 - Create, save and load your own palettes, or edit the current palette on the go.
 - Apply the pencil and ink bucket tools with either a color or the eraser.
 - Zoom and pan your sprite using two-finger gestures.
 - Create and combine selections using a resizable rectangle, pixel by pixel or the magic wand.
 - Move selections around.
 - Move all sprite pixels up and down row by row, or left and right column by column.
 - Undo/redo your recent editor actions.
 - Display or hide a preview of your image.
 - Load and save your sprites.
 - Export your sprites to PNG and SVG.
